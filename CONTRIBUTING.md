# Contributing

Thank you for your interest in Aether Maxwell Studio.

## Ways to Contribute

- Documentation
- Bug fixes
- Features
- Unit tests
- Performance improvements
- Solver development
- CAD development
- UI improvements

## Workflow

1. Fork the repository.
2. Create a feature branch.
3. Commit your changes.
4. Submit a Pull Request.

## Coding Standards

- C++20
- Qt 6
- SOLID principles
- RAII
- Smart pointers
- CMake

## Pull Requests

Please include:

- Description
- Motivation
- Screenshots (if applicable)
- Tests
- Documentation updates

## Communication

Please be respectful and constructive.
